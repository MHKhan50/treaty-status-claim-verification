# Data governance

- **Source:** UNODA Treaties Database, processed by Our World in Data; licence CC BY 4.0. Attribution is given in the
  README, data README and citation file.
- **No redistribution:** the tables are downloaded at run time; the manifest records URL, retrieval time, rows and SHA-256.
- **Scope:** treaty participation only. The corpus contains no technical information on weapons, materials, delivery
  systems, deployments or targeting, and the project does not produce any.
- **Interpretation:** labels state whether the published records support a claim. They are not legal opinions, treaty
  compliance findings or intelligence assessments; status categories are simplified by the data publisher.
